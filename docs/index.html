Recording that doesn't break. Clips that don't get lost. Запись, которая не ломается. Клипы, которые не теряются.

ClipKeeper sits in the tray next to OBS, watches the replay buffer from the outside and fixes what breaks by itself — then helps you find, trim and share the clip. ClipKeeper живёт в трее рядом с OBS, следит за буфером повтора снаружи и сам чинит то, что ломается, — а потом помогает найти, обрезать и отправить клип.

WhyЗачем

You press "Save Replay". The clip should actually be there. Ты жмёшь «Сохранить повтор». Клип должен действительно получиться.

With the right devices, all audio tracks and a live picture — not four seconds of silence found a week later. С нужными устройствами, всеми дорожками и живой картинкой — а не четыре секунды тишины, которые найдутся через неделю.

Two halvesДве половины

Guards the recording. Keeps the clips. Следит за записью. Хранит клипы.

Both work on their own — turn off the one you don't need in Settings → General. Обе работают и по отдельности — ненужную можно выключить в «Настройки → Общие».

Recording guardНаблюдение за записью

Talks to OBS through obs-websocket, from the outside — no plugin, no script. Общается с OBS через obs-websocket, снаружи — без плагинов и скриптов.

  • Keeps sources on the right audio devices and monitorsДержит источники на нужных звуковых устройствах и мониторах
  • Restarts a crashed replay buffer — and OBS itself after a crashПерезапускает упавший буфер повтора — и сам OBS после падения
  • Notices silent audio and a black or frozen pictureЗамечает пропавший звук и чёрную или застывшую картинку
  • Checks every saved clip: length, tracks, dropped framesПроверяет каждый клип: длина, дорожки, потерянные кадры
  • Low disk space, GPU driver failures, a daily OBS settings backupМало места на диске, сбои драйвера, ежедневная копия настроек OBS

Trim editorРедактор

Trim on the timeline you already knowОбрезка на привычном таймлайне

Filmstrip, waveform of what you actually hear, each track in its own lane. Cut pieces from the middle with X, save lossless, frame-exact on the GPU, or sized for sharing. Every saved file is checked: length, video, audio in each track. Раскадровка, волна того, что реально слышно, каждая дорожка на своей полосе. Вырезай куски из середины клавишей X, сохраняй без потерь, по кадру на видеокарте или под размер для отправки. Каждый файл проверяется: длина, видео, звук в каждой дорожке.

InstallУстановка

Running in a minuteРаботает через минуту

Download and unpackСкачай и распакуй

ClipKeeper-<version>.zip from Releases into a folder of your own. ffmpeg is already inside. ClipKeeper-<версия>.zip со страницы Releases в свою папку. ffmpeg уже внутри.

Enable WebSocket in OBSВключи WebSocket в OBS

Tools → WebSocket Server Settings. No need to copy the password — the setup finds it. «Сервис → Настройки сервера WebSocket». Пароль копировать не нужно — настройка найдёт его сама.

Run ClipKeeper.exeЗапусти ClipKeeper.exe

A short setup walks through language, features, the OBS connection, devices and folders. Updates itself from GitHub. Короткая настройка: язык, функции, подключение к OBS, устройства и папки. Обновляется сам с GitHub.

"Windows protected your PC"? The exe is not code-signed yet, so SmartScreen doesn't know it — press More info → Run anyway. Every release is built by GitHub Actions from this repository; compare the file with SHA256SUMS.txt from the release or check it on VirusTotal. «Система Windows защитила ваш компьютер»? Exe пока не подписан, и SmartScreen его не знает — нажми «Подробнее → Выполнить в любом случае». Каждый релиз собирает GitHub Actions из этого репозитория; сверь файл с SHA256SUMS.txt из релиза или проверь на VirusTotal.
PrivacyПриватность

Everything stays on your computerВсё остаётся на твоём компьютере

No accountsБез аккаунтов

No telemetry, no ads. Settings, cache and stats live next to the exe.Ни телеметрии, ни рекламы. Настройки, кэш и статистика лежат рядом с exe.

Encrypted passwordПароль зашифрован

OBS on your PC; Steam and Wikipedia for covers; GitHub for updates. The last two can be turned off.OBS на твоём ПК; Steam и Википедия — обложки; GitHub — обновления. Последние два выключаются.
